Privacy Policy

Last updated: November 10, 2026

Who uses this app

Claude Workspace MCP is a personal tool. Its only users are Michael Eck's own Google accounts. It is not offered to the public.

What data it accesses

With the account owner's consent, the app accesses Gmail, Google Drive, Google Docs, Google Sheets, and Google Calendar data for the signed-in account, only to carry out tasks the account owner requests.

How data is stored and shared

OAuth tokens are stored only on the owner's own computer. Google user data is not sold, not shared with third parties, not used for advertising, and not used to train generalized AI or machine learning models. Data is processed only to perform the owner's requested tasks, which may include sending it to the AI assistant the owner uses for that purpose.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from your Google Account permissions page.
